# Diệu Thảo — Business Analyst Portfolio

A high-performance personal portfolio website for **Diệu Thảo** (Business Analyst Intern), built with **Astro**, **TypeScript**, **Tailwind CSS**, and **GSAP**.

Designed with an editorial light theme featuring a clean white background, dark slate typography, and sky blue accents, with layout and animations inspired by [jackelder.design](https://www.jackelder.design/#home) and content structured according to [Mokkup.ai's Business Analyst Portfolio Framework](https://www.mokkup.ai/blogs/how-to-build-your-portfolio-as-a-business-analyst/).

---

## 🌟 Key Features

- **Light Aesthetic & Modern Typography**: Clean white surface (`#FFFFFF` / `#F8FAFC`) paired with deep slate typography (`#0F172A`) and subtle Sky Blue accents (`#0284C7`).
- **Smooth 60 FPS GSAP Motion**:
  - Interactive Preloader with numeric counter curtain animation.
  - Custom fluid magnetic cursor follower with interactive expansion on project cards.
  - Staggered hero entrance reveals and scroll-triggered section transitions.
  - Infinite horizontal marquee ticker showcasing core competencies.
- **BABOK® & Mokkup.ai Aligned Structure**:
  - **Hero**: Core BA identity and focus areas.
  - **Featured Case Studies**: 6 end-to-end BA projects with Problem → Analysis → Business Outcome breakdown.
  - **About & Profile**: Bio, education (UFLS Danang, GPA 3.7/4.0), and core BA value proposition.
  - **Experience & Credentials**: Verified ITBA Certification (UDECAREER 2026), IELTS 7.5, and academic history.
  - **Toolkit & Chart Storytelling**: 4 core BA capability pillars and interactive chart selection guide.
  - **Contact**: Interactive one-click email copying (`dieuthao.tpqn@gmail.com`) and external profile links.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Animation**: [GreenSock GSAP](https://gsap.com/) & ScrollTrigger
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Type Checking**: TypeScript

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Install dependencies
npm install

# Start local development server (http://localhost:4321)
npm run dev

# Build production static bundle
npm run build

# Run type checker
npm run build-types
```
